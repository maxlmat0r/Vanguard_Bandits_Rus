# Тексты перевода

Каждый JSON-файл соответствует одному файлу игры (номер в имени — номер файла в архиве `EPICA.BIN`).

| Папка | Префикс | Что внутри | Ширина строки | Строк |
|---|---|---|---|---|
| `story/` | `s` | сюжетные сцены | 238 px | 3 + имя |
| `battle/` | `b` | диалоги в боях | 238 px | 3 + имя |
| `quips/` | `q` | выкрики в анимации боя | 150 px | 2 |
| `camp/` | `x` | `x417` — подсказки Пака, `x419` — разговоры у костра | как в оригинале | как в оригинале |
| `ui/` | `exe_ui`, `m0`–`m2` | меню, магазин, предметы, настройки | не длиннее оригинала | — |

Имена, места и термины — в [GLOSSARY.md](GLOSSARY.md), голоса персонажей — в [../docs/STYLE.md](../docs/STYLE.md).

## Формат

Пример из `story/s648.json` (заставка перед первым боем):

```json
{
 "id": 0,
 "en": "Bastion:\nFather, I simply can't wait to slay\nthese wretched dogs!",
 "ru": "Бастион:\nОтец, мне не терпится сразить\nэтих мерзких псов!"
}
```

- **`en`** — оригинал, менять не нужно.
- **`ru`** — перевод, его и правим. Пустая строка означает, что в игре останется оригинал.
- **`\n`** — перенос строки. Первая строка с двоеточием (`Бастион:`) — имя говорящего, оно не входит в лимит строк.
- **`{XX}`** — служебный байт игры: меню выбора (`{02}…{00}{00}…`), коды персонажей. Оставляйте как есть.
- В файлах `ui/` есть служебные поля (`addr`, `refs`, `ptrs`, `room`) — их не трогайте. `room` — сколько байт строка может занять на своём месте; более длинные сборка переносит сама.

## Проверка

```sh
python3 scripts/check_all.py
```

Скрипт проверяет ширину каждой строки в пикселях (по таблице ширин шрифта игры), число строк, смешение латиницы и кириллицы в одном слове и буквы, которых нет в шрифте.

## Инструменты переводчика

| Команда | Что делает |
|---|---|
| `python3 scripts/en.py -todo s648` | показать непереведённые строки файла |
| `python3 scripts/put.py s648 < блоки` | записать перевод блоками `@id` с автопереносом по ширине |
| `python3 scripts/tm.py` | подставить перевод в одинаковые английские строки |
| `python3 scripts/mod_put.py m1 < строки` | перевод строк интерфейса модулей: `английский<TAB>русский` |
| `python3 scripts/exe_put.py < строки` | перевод строк интерфейса EXE: `id<TAB>русский` |

Пример ввода для `put.py`: перенос расставится сам, а `//` задаёт принудительный перенос.

```
@0
Бастион:
Отец, мне не терпится сразить этих мерзких псов!
```
