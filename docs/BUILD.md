# Сборка образа из исходников

Готовый патч лежит в [`patch/`](../patch/). Сборка нужна, только если вы правите тексты или графику и хотите проверить результат в игре.

## Что понадобится

- **Python 3.9+** — для сборки, внешние пакеты не нужны.
- **[mkpsxiso / dumpsxiso](https://github.com/Lameguy64/mkpsxiso)** 2.x — разборка и сборка образа диска.
- **Ваш образ** американской версии (SLUS-01070), формат `.bin`/`.img` + `.cue` с секторами 2352 байта.
- **xdelta3** — только если собираете патч.

## Шаги

Все команды выполняются из корня репозитория.

**1. Разберите образ.** Файлы попадут в `extracted/`, вместе с лицензионным блоком диска:

```sh
dumpsxiso -x extracted -s extracted/project.xml "Vanguard Bandits.cue"
```

**2. Сохраните оригиналы.** Сборка всегда начинает с чистых файлов из `orig/`:

```sh
mkdir -p orig
cp extracted/EPICA.BIN extracted/SLUS_010.70 orig/
```

**3. Соберите переведённые файлы.** Скрипт берёт тексты из `texts/`, графику из `assets/` и записывает новые `extracted/EPICA.BIN` и `extracted/SLUS_010.70`:

```sh
python3 scripts/build.py .
```

**4. Соберите образ:**

```sh
mkpsxiso -y build/disc.xml
```

Получится `Vanguard Bandits RUS.bin` и `.cue`, их можно сразу открыть в эмуляторе.

**5. Соберите патч** (необязательно):

```sh
xdelta3 -e -9 -B 1073741824 -s "Vanguard Bandits.img" "Vanguard Bandits RUS.bin" "patch/Vanguard Bandits RUS.xdelta"
```

## Проверки

```sh
python3 scripts/check_all.py      # ширина и число строк во всех текстах
python3 scripts/tm.py             # подставить перевод в одинаковые строки
```

## Графика

Перерисованная графика уже лежит в [`assets/`](../assets/). Пересоздавать её нужно, только если меняете надписи на картинках. Скрипты используют Pillow и шрифты macOS из `/System/Library/Fonts/Supplemental/`; на другой системе поправьте путь к шрифту в начале скрипта.

| Скрипт | Что создаёт | Шрифт |
|---|---|---|
| `gen_title.py` | главный экран (подпись) и меню СТАРТ / ЗАГРУЗКА / НАСТРОЙКИ | Arial Narrow, пиксельный |
| `gen_loctitles.py` | 53 названия местностей | Luminari |
| `gen_gameover.py` | КОНЕЦ ИГРЫ | Georgia Bold |
| `gen_loading.py` | «Загрузка...» | Georgia |
| `gen_ui8.py` | «ДОП. ИНФО» | пиксельный |

```sh
pip install pillow
python3 scripts/gen_loctitles.py .
```

## Как устроена игра

Коротко, для тех, кто полезет глубже. Подробности в комментариях к скриптам.

- **`EPICA.BIN`** — архив из 704 файлов. Таблица в начале содержит смещения и размеры (LE u32), файлы выровнены по 2048 байт. Игра ищет файлы по номеру, поэтому выросший файл сборка просто переносит в конец архива.
- **Сжатие** — LZSS с окном 1024 байта, заполненным нулями (`scripts/lz.py`).
- **Тексты:**
  - файлы 121–176 — диалоги в боях (`battle_fmt.py`);
  - 482–700 — сюжетные сцены (`story_fmt.py`);
  - 358–409 — выкрики (`quip_fmt.py`);
  - 417 и 419 — архивы с таблицами строк (`sect_fmt.py`, `strtab_fmt.py`);
  - файлы 0–2 — программные модули, загружаемые по адресу `0x800751a8`, со строками интерфейса.
- **Кириллица:**
  - в основном шрифте (файл 7) буквы стоят на кодах `0xB0–0xCF` и на местах неиспользуемых символов ASCII; похожие на латинские берутся из латиницы (`cyr_glyphs.py`);
  - таблицы ширин букв перенесены в свободную память EXE;
  - вывод мелкого шрифта и шрифта 8×8 дополнен небольшими вставками кода (`build.py`, функции `patch_exe`, `patch_font8_exe`, `patch_modules`).
- **Графика:**
  - главный экран, его меню и заставки — архив 413;
  - «КОНЕЦ ИГРЫ» — 420;
  - названия местностей — секция 6 сюжетных файлов 648–700;
  - лист интерфейса с «ДОП. ИНФО» и «Загрузка...» — файл 8.
