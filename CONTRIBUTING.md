# Как помочь с переводом

Спасибо, что хотите улучшить перевод. Чаще всего помощь — это правка текста, и для неё не нужны ни игра, ни программирование.

## Сообщить об ошибке

Откройте [Issue](../../issues) и приложите:

- скриншот места, где видна ошибка;
- где это в игре: глава, бой или меню;
- что не так и как, по-вашему, должно быть.

Если не уверены, как исправить, тоже пишите: обсудим.

## Исправить текст самому

1. **Найдите строку.** Все тексты лежат в [`texts/`](texts/), по файлу на каждый файл игры. Удобнее всего искать по английскому оригиналу или по русской фразе со скриншота: поиск по репозиторию на GitHub или `grep -rn "фраза" texts/`.
2. **Исправьте поле `"ru"`.** Поле `"en"` и всё остальное не трогайте. Формат описан в [texts/README.md](texts/README.md).
3. **Проверьте ширину строк**, если у вас есть Python 3:
   ```sh
   python3 scripts/check_all.py
   ```
   Должно быть `problems: 0`. Игра для проверки не нужна. Та же проверка автоматически запускается для каждого pull request.
4. **Отправьте pull request.** В описании коротко объясните, что и почему меняете. Если правка касается имени или термина, обновите и [глоссарий](texts/GLOSSARY.md).

Через веб-интерфейс GitHub всё это можно сделать без установки чего-либо: откройте файл, нажмите карандаш, исправьте и предложите изменение.

## Правила

- **Имена и термины** — строго по [глоссарию](texts/GLOSSARY.md). Если считаете, что название стоит изменить, сначала откройте Issue: одно имя встречается в сотнях строк.
- **Голоса персонажей** — по [руководству по стилю](docs/STYLE.md): акцент Закова, «типа» у Клэр, перевёрнутые фразы Халак и так далее.
- **Переносы строк** (`\n`) расставлены под ширину окна игры. После правки проверьте их скриптом.
- **Служебные метки** в фигурных скобках (`{02}`, `{00}`, `{03}`) не трогайте: это меню выбора и коды игры.
- **Строки без английского текста** (паузы вроде `...   ...   ...`) не переводятся.
- **Одна правка — один смысл.** Не смешивайте в одном pull request исправление опечатки и переписывание сцены.
